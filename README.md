# Verificador de Senhas Fracas

Projeto desenvolvido em Python.

É um programa que verifica se as senhas digitadas pelo usuário são consideradas fracas.




## O que o programa faz:

O programa verifica se as senhas digitadas pelo usuário são fracas ou não atraves de duas condicões:

1 - Se as senhas tiverem menos de 8 caracteres.
2 - Ou se as senhas forem exatamente iguais a que estão na lista de senhas fracas do código-fonte.


## Conceitos chave de Python:

Entrada e saída de dados,lacos de repeticao,funcões e estrutura de dados.
